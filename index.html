1. Acesso e Sessão

A aplicação abre em modo de leitura — podes consultar tudo sem fazer login. Para editar qualquer dado é necessário ter sessão activa.

Iniciar sessão

  1. Clica Entrar (canto superior direito)
  2. Serás redireccionado para o login do GitLab (git.inegi.up.pt)
  3. Autentica com as tuas credenciais da empresa
  4. Volta à aplicação com sessão iniciada no teu nome
Na próxima visita o login é automático — o token fica guardado no browser.

Terminar sessão

Clica Sair no canto superior direito. O checkout fica registado no diário de alterações.

Modo de leitura

Enquanto não tiveres sessão activa aparece uma barra amarela: 🔒 Modo de leitura — inicia sessão para fazer alterações. Qualquer tentativa de edição redireccionará para o login.

4. Alocações

Tabela principal com todos os registos. Filtra por pessoa, projecto ou texto livre.

Criar uma alocação

  1. Clica + Nova Alocação
  2. Preenche os campos obrigatórios: Pessoa, Projecto, Início, Fim, Horas totais
  3. Opcionalmente: WP, Atividade, distribuição mês-a-mês personalizada
  4. Clica Guardar
Para distribuir horas de forma desigual pelos meses, usa a secção Distribuição mês a mês no formulário.

Editar / Eliminar

Usa os ícones ✏️ e 🗑️ em cada linha da tabela.

Limpar todas as alocações

Botão Limpar Tudo (vermelho). Remove todos os registos mas mantém pessoas, projectos e capacidades.

7. Por Projeto

Distribuição de horas e pessoas por projecto no ano seleccionado.

  • Donut chart — proporção de horas por projecto
  • Matriz pessoa × projecto — horas cruzadas
  • Catálogo de projectos — adicionar, activar/desactivar, eliminar projectos

Clica no nome de um projecto para o activar/desactivar. Projectos inactivos não aparecem nos dropdowns de nova alocação.

8. Equipa

Membros

Adiciona pessoas com nome e capacidade mensal por omissão (padrão: 140h). Remove com o ícone 🗑️ (só se não tiver alocações).

Capacidade mensal

Tabela editável com horas disponíveis por pessoa × mês. Selecciona o ano e clica directamente nas células para editar. Célula vazia = 140h. Guarda ao sair da célula.

As capacidades são usadas para calcular as percentagens de utilização em todo o planeamento.

9. Arquivo

Histórico de snapshots mensais do plano — útil após cada revisão de chefes de equipa.

Submeter um plano

  1. Clica ↑ Submeter Plano quando o plano do mês estiver finalizado
  2. Selecciona o mês do plano e adiciona uma nota opcional
  3. Clica Guardar no arquivo

Consultar / Restaurar / Eliminar

Clica Ver numa linha do arquivo para abrir o snapshot. A partir daí podes Restaurar estado (substitui os dados actuais) ou Eliminar do arquivo.

⚠️ Restaurar substitui permanentemente os dados actuais. Faz um backup (Dados → Descarregar JSON) antes se necessário.

Perguntas Frequentes

As alterações são guardadas automaticamente?

Sim. Cada operação guarda imediatamente no servidor. Não há botão "Guardar".

Posso usar em simultâneo com colegas?

Sim, mas evita editar o mesmo registo ao mesmo tempo. A última gravação prevalece.

Fechei o browser sem fazer Sair. E agora?

Os dados ficam guardados. A sessão fica activa até fazeres Sair explicitamente ou o token expirar (~2h).

Fiz algo errado. Como reverter?

Usa o Arquivo se tinhas um snapshot recente, ou Dados → Carregar JSON se tens um backup manual.
